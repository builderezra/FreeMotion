# FreeMotion original display fonts

This set contains six original Latin display families. `build_fonts.py` draws Aster Round and Circuit Sans from geometric centerlines. `build_meridian.py` separately draws Meridian Serif with high-contrast contours, flared serifs, and independently constructed glyphs. `build_lilt.py` draws Lilt Marker with hand-placed irregular loops, flowing strokes and a gentle right lean. `build_vector_mono.py` draws Vector Mono with geometric square-ended strokes and a fixed 700-unit advance. `build_foundry_slab.py` draws a broad, low-contrast slab face with heavy rectangular terminals and individually placed proportional glyphs. The generators write TrueType and WOFF2 files. The proportional families add native kerning pairs; Vector Mono deliberately does not. They do not import a base font, trace existing glyph outlines, or copy another font's metrics. The Python packages in `requirements.txt` are build tools; their font files are not inputs.

| Family | Design | Files |
| --- | --- | --- |
| FM Aster Round | Friendly open forms, rounded terminals, wider spacing | Regular and Bold |
| FM Circuit Sans | Condensed proportions, square terminals, angular polygonal bowls | Regular and Bold |
| FM Meridian Serif | Editorial high contrast, fine crossbars, flared serifs and open lowercase | Regular and Bold |
| FM Lilt Marker | Readable casual hand lettering with rounded marker strokes | Regular and Bold |
| FM Vector Mono | Wide geometric monospaced letters for timers, credits and tech titles | Regular and Bold |
| FM Foundry Slab | Wide, sturdy slab serif for headlines, sports cards and posters | Regular and Bold |

Aster Round and Circuit Sans each map 287 Unicode characters: A–Z, a–z, digits, common punctuation, currency and quote symbols, plus many accented Latin-1 and Latin Extended-A characters. Meridian Serif maps 105 characters: basic Latin letters, digits, common punctuation and signs, and several typographic quotes and dashes. Lilt Marker maps all 95 printable ASCII characters plus thirteen typographic marks and currency symbols (108 total). Vector Mono and Foundry Slab each map 178 characters: all 95 printable ASCII characters plus common European accented Latin letters, punctuation and currency signs. Meridian and Lilt are intended for short English titles; unsupported accents and scripts use the CSS fallback. All six families use 1000 units per em and include Regular/Bold marked 400/700. GPOS kerning covers common pairs such as AV, To, and Ya in proportional families; Vector Mono stays fixed-width. The OS/2 embedding flag is 0 (installable embedding).

These are display fonts intended for FreeMotion titles, labels, and graphics. `preview.png` shows Aster and Circuit; `preview-32-48.png` checks their sentence readability at actual 32 px and 48 px sizes. `fm-meridian-serif-preview.png`, `fm-lilt-marker-preview.png`, `fm-vector-mono-preview.png` and `fm-foundry-slab-preview.png` show the newer families' letterforms and both weights. Lilt, Vector Mono and Foundry Slab specimens include real 32 px and 48 px samples. Keep a fallback font for scripts and symbols outside each family's coverage. FreeMotion can set its own distribution terms for these generated assets.

FM Vector Mono was created for FreeMotion from the source geometry in `build_vector_mono.py`. The generator does not read a third-party font file; the resulting Regular and Bold files may be bundled, modified and used in FreeMotion and its users' videos without an external font-vendor fee or attribution. This provenance/use statement applies only to the original fonts here; `fonts/open/` retains each upstream designer's licence notice.

FM Foundry Slab was created for FreeMotion from the source geometry in `build_foundry_slab.py`. No third-party font file or outlines are used. Its Regular and Bold files may be bundled, modified and used in FreeMotion and its users' videos without an external font-vendor fee or attribution. This note does not override the separate notices for `fonts/open/`.

To regenerate: install `requirements.txt`, run `python build_fonts.py`, `python build_meridian.py`, `python build_lilt.py`, `python build_vector_mono.py` and `python build_foundry_slab.py`, then run the `render_*.py` scripts. Each generator stages its faces before updating the WOFF2 files in `fonts/original/` that the app actually loads. TrueType intermediates remain in `source/fonts/` for the specimen renderers. `fonts.css` shows the browser family names and weights.
