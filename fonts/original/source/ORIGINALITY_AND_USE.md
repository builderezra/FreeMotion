# FreeMotion original display fonts

This set contains ten original Latin display families. `build_fonts.py` draws Aster Round and Circuit Sans from geometric centerlines. `build_meridian.py` separately draws Meridian Serif with high-contrast contours, flared serifs, and independently constructed glyphs. `build_lilt.py` draws Lilt Marker with hand-placed irregular loops, flowing strokes and a gentle right lean. `build_vector_mono.py` draws Vector Mono with geometric square-ended strokes and a fixed 700-unit advance. `build_foundry_slab.py` draws a broad, low-contrast slab face with heavy rectangular terminals and individually placed proportional glyphs. `build_cloud_pop.py` draws wide, upright, cushion-like letters from independently placed paths and broad rounded terminals. `build_signal_pixel.py` hand-plots proportional 7×9 stepped glyphs for retro titles and HUD graphics. `build_aperture_stencil.py` plots a separate industrial open-counter alphabet with chamfered bowls, square terminals, cut bridges and small-cap lowercase. `build_ribbon_script.py` draws a slanted sign-writing face from individually placed flowing strokes, broad downstrokes, fine returns and asymmetric ovals. The generators write TrueType and WOFF2 files. The proportional continuous-outline families add native kerning pairs; Vector Mono and Signal Pixel deliberately do not. They do not import a base font, trace existing glyph outlines, or copy another font's metrics. The Python packages in `requirements.txt` are build tools; their font files are not inputs.

Aster Round and Circuit Sans each map 287 Unicode characters: A–Z, a–z, digits, common punctuation, currency and quote symbols, plus many accented Latin-1 and Latin Extended-A characters. Meridian Serif maps 105 characters: basic Latin letters, digits, common punctuation and signs, and several typographic quotes and dashes. Lilt Marker maps all 95 printable ASCII characters plus thirteen typographic marks and currency symbols (108 total). Vector Mono, Foundry Slab and Cloud Pop each map 178 characters: all 95 printable ASCII characters plus common European accented Latin letters, punctuation and currency signs. Signal Pixel maps 161 characters: printable ASCII, common accents, Ł/ł and a bullet. Aperture Stencil maps 223 characters: printable ASCII, many European accents, typographic punctuation and currency signs. Ribbon Script maps 227 characters: printable ASCII, many European accents, typographic punctuation and currency signs. Meridian and Lilt are intended for short English titles; unsupported accents and scripts use the CSS fallback. All ten families use 1000 units per em and include Regular/Bold marked 400/700. GPOS kerning covers common pairs such as AV, To, and Ya in the continuous-outline proportional families; Vector Mono stays fixed-width and Signal Pixel retains its grid spacing. The OS/2 embedding flag is 0 (installable embedding).

These are display fonts intended for FreeMotion titles, labels, and graphics. `preview.png` shows Aster and Circuit; `preview-32-48.png` checks their sentence readability at actual 32 px and 48 px sizes. Each newer family has a named `*-preview.png` specimen beside its generator, including `fm-aperture-stencil-preview.png` and `fm-ribbon-script-preview.png`. Lilt, Vector Mono, Foundry Slab, Cloud Pop, Signal Pixel, Aperture Stencil and Ribbon Script specimens include real 32 px and 48 px samples. Keep a fallback font for scripts and symbols outside each family's coverage. FreeMotion can set its own distribution terms for these generated assets.

To regenerate: install `requirements.txt`, run `python build_fonts.py`, `python build_meridian.py`, `python build_lilt.py`, `python build_vector_mono.py`, `python build_foundry_slab.py`, `python build_cloud_pop.py`, `python build_signal_pixel.py`, `python build_aperture_stencil.py` and `python build_ribbon_script.py`, then run the `render_*.py` scripts. Each generator stages its faces before updating the WOFF2 files in `fonts/original/` that the app actually loads. TrueType intermediates remain in `source/fonts/` for the specimen renderers. `fonts.css` shows the browser family names and weights.
