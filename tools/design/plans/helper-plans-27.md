## #845 Audio glitches once effects are on a sound

**Verdict: one real, measured waste in the live chain, fixed with a patch and test. Whether it cures his glitch is a Guess; the item still needs his paste of "Your last playback".**
- **Measured.** `applyAt` (`js/audio-fx.js`, the live chain's per-frame call) rewrote every param of every effect with `setValueAtTime` on every frame, with nothing moving. At 60 fps: 1 effect 240 events/s, 5 effects 1020/s, 12 effects 3420/s; across all 27 effects 15,960 events per 120 frames (`scripts/aw.js`, `aw_per.js`). The CPU cost in Chromium is small (about 0.02 ms a frame for 5 effects), so on a desktop this is not the glitch. On an iPhone each event is an insertion into the param's timeline (Guess), which fits "fine until effects, then glitches".
- **Patch** (`p27-845-src.patch`, +11/-2, `audio-fx.js?v=16` to `17`; `p27-845-tests.patch`): `applyAt` remembers the last value written per param and skips a write when the value is unchanged and the param is not keyframed. First frame always writes; a moved slider writes once; a keyframed param still writes every frame. Result across all 27 effects: **15,960 to 133 events per 120 frames** (99%). A first variant that only skipped plain single-param effects removed just 28% (Reverb, Delay, Flanger, Chorus and others write through custom setters), so it was dropped.
- **Test** `P27 #845 …`: six effects including Reverb, Delay, Chorus, Flanger and Pitch at rest add no events after frame one; a slider moved 0 to 6 dB writes once as 1.995; a keyframed Gain and a keyframed Chorus param write every frame. **Red on main** (1003 more events on 59 frames, first frame 17), **green with the patch at 1280 and 380**. Mutations: drop the "remember" line CAUGHT, skip always CAUGHT.
- **Neighbours** (1280, red sets identical to main): `audio` 51/57 vs 50/56 (the +1 is the new test), `482 3` 23/24 both, `sound` 43/53 both, `pitch` 6/6, `Hear` 2/3 both (1 not run here), `live` 38/42 vs 37/41. The reds are the container's missing video/AAC codec.
- **Risk (Read):** the skip assumes nothing else writes those nodes between frames. The only other writers in `audio-fx.js` are Pitch Shift's own ramp (`reshape`, only on a change) and the cancel at line 332; the chain is rebuilt on any structure change, which drops the cache. Pitch tests are green. Ask for his paste first if you want proof it was the cause.
