Quick & Full

Any project opens in either editor, nothing gets converted, clips stick together in Quick, the things on a clip go with it, and you and a friend can each use a different editor on the same project at the same time.

  • Quick is the new, simple editor
  • Full is today's editor
  • The real names are yours to pick (decision D1)
