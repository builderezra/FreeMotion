## Scope and exclusions

I searched `REQUESTS.md` and `audits/*.json` for storage sanitizers, imported values, layer/project/media fields, collaboration operation types and prototype keys. Prototype-key/collaboration fuzz hardening is already described in REQUESTS.md around line 15135 and in the #921 S8 entry; I treat it as prior work and do not report it again. This is a source-derived type table; I did not execute a six-type dynamic matrix. “Pass” means the sanitizer retains or forwards the input representation; it does not assert that every later renderer path supports it.

Type columns use JSON values: string, finite number, boolean, array, null. “Crash” means source semantics can throw before the sanitizer completes; it is marked UNVERIFIED because I did not run the malformed fixture.
