run only these tests

?items=a,b,c — run only tests with those item tags, in suite order.
?from=N&to=M — run a slice of the suite by run-order index instead.
Built for the question "does this test fail on its own, or only after something earlier ran?", which is the question a change that turns unrelated tests red always comes down to. Isolating by hand meant editing a probe page each time; this asks it in one command.
